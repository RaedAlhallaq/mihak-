# Project Brief: Mahak AI (مشروع مَحَكّ)

## Problem Statement
AI developers face cost unpredictability, latency bottlenecks, and hidden regressions when switching or updating LLMs, often relying on subjective "vibe-checking" instead of empirical benchmarks.

## Solution & Goal
Build Mahak AI—a full-stack sandbox platform built on Next.js & TypeScript that allows developers to run prompt datasets across multiple LLMs in parallel (fan-out), calculating token usage, financial cost, latency, and quality scores via LLM-as-a-Judge.

## Target Audience
Full-stack & AI Software Engineers needing empirical cost-quality tradeoffs.

## Success Criteria
Execute multi-model evals via Mahak AI with 100% accurate token/cost calculation and UI dashboard rendering in <60 seconds.
